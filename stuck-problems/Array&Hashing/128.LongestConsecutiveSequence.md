## 4) Final approach (in plain English)

- First, I convert the list into a set so I can quickly check whether a number exists and remove duplicates.
- I initialize max_length = 0 to keep track of the longest consecutive sequence.
- I loop through each number and check if num - 1 is missing. If it is, that means I've found the starting number of a sequence.
- I initialize length = 1 and use a while loop to check whether the next consecutive numbers (num + 1, num + 2, etc.) exist.
- For every consecutive number found, I increase the length by 1.
- Once the sequence ends, I update max_length with the maximum length found so far.
- Finally, I return max_length, which represents the longest consecutive sequence.

## 5) Code (final)

```python
class Solution:
    def longestConsecutive(self, nums: List[int]) -> int:
        char_set=set(nums)
        max_length=0
        for num in char_set:
            if num-1 not in char_set:
                char_set.add(num)
                length=1 #if no lower number

                while num+length in char_set:
                    length=length+1
                max_length=max(max_length, length)
            print(max_length)
        return max_length
```
