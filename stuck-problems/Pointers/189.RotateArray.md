## 4) Final approach (in plain English)

1. **Trim k first.** If you rotate 7 items by 10, that's the same as rotating by 3, because every 7 rotations you're back where you started. So `k %= n`.
2. **Flip the whole thing.** `[1,2,3,4,5,6,7]` becomes `[7,6,5,4,3,2,1]`. Now the numbers that should be at the front (5, 6, 7) are at the front, just backwards.
3. **Flip the first k back.** `[7,6,5]` becomes `[5,6,7]`. Front part is fixed.
4. **Flip the rest back.** `[4,3,2,1]` becomes `[1,2,3,4]`. Done: `[5,6,7,1,2,3,4]`.

## 5) Code (final)

```python
class Solution:
    def rotate(self, nums: list[int], k: int) -> None:
        """
        Do not return anything, modify nums in-place instead.
        """
        n=len(nums)
        k%=n
        nums.reverse()
        nums[:k]=reversed(nums[:k])
        nums[k:]=reversed(nums[k:])
        return nums
```
