## 4) Final approach (in plain English)

1. Split the sentence into words: I use s.split() to break the string into individual words. This also removes extra spaces.
2. Push words onto a stack: I go through each word and add it to a stack using stack.append(word).
3. Pop words from the stack: Since a stack follows LIFO (Last In, First Out), the last word added comes out first. I keep popping words and adding them to a result list.
4. Join the reversed words: Finally, I use ' '.join(res) to combine all the words into a single string with one space between them.

Steps of the solution like you’d explain to a friend.

## 5) Code (final)

```python
class Solution:
    def reverseWords(self, s: str) -> str:
        stack=[]
        res=[]
        for word in s.split():
            stack.append(word)

        while stack:
            res.append(stack.pop())
        return ' '.join(res)
```
