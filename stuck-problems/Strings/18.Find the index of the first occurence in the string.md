## 4) Final approach (in plain English)

1. Check if the needle is empty: If needle is empty, I return -1 in my original code.
2. Start checking each position: I use i to go through the haystack, stopping when there aren't enough characters left to match the needle.
3. Reset the variables: For every new starting position, I reset j = 0 and prefix = "" so I can start comparing from the beginning of the needle.
4. Compare characters one by one: I compare haystack[i+j] with needle[j]. If they match, I add that character to prefix and move j forward.
5. Check for a complete match: Whenever prefix becomes equal to needle, I return i, which is the starting index where the word was found.
6. Move to the next position: If the characters don't match, I increment i and try again from the next position.
7. Return -1 if nothing matches: If I finish checking all possible starting positions without finding the needle, I return -1.
   Steps of the solution like you’d explain to a friend.

## 5) Code (final)

```python
class Solution:
    def strStr(self, haystack: str, needle: str) -> int:
        if not needle:
            return -1
        i=0
        while i<=len(haystack)-len(needle):
            j=0 #this is to reset the index in the needle
            prefix="" #this is to reset
            while j<len(needle) and haystack[i+j]==needle[j]:
                prefix=prefix+haystack[i+j]
                j=j+1
                if prefix==needle:
                    return i
            i=i+1
        return -1
```
