## 4) Final approach (in plain English)

- take 3 pointers of lengths m-1, n-1, m+n-1
- then first while loop of p1>=0 and p2>=0 keep the larger numbers at the end of the first array
- second while loop traverse the remaning second array if still all elements are not traversed through.
  Steps of the solution like you’d explain to a friend.

## 5) Code (final)

```python
# paste final accepted code here
class Solution:
    def merge(self, nums1: List[int], m: int, nums2: List[int], n: int) -> None:
        """
        Do not return anything, modify nums1 in-place instead.
        """

        p1=m-1
        p2=n-1
        p=m+n-1
        while p1>=0 and p2>=0:
            if nums1[p1]>nums2[p2]:
                nums1[p]=nums1[p1]
                p1=p1-1
            else:
                nums1[p]=nums2[p2]
                p2=p2-1
            p=p-1
        while p2>=0:
            nums1[p]=nums2[p2]
            p2=p2-1
            p=p-1
```
