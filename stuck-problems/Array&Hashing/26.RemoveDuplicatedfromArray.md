## 4) Final approach (in plain English)

Steps of the solution like you’d explain to a friend.

- if the array is empty return 0 as the unique elements number is asked
- take pointer i initiated at 0
- do for loop and when two adjacent elements are not same incrememnt the i pointer by 1 and keep the for loop value in array[i] place as we are planning to return i+1 which basically counts the number of unique elements in the array

---

## 5) Code (final)

```python
# paste final accepted code here
class Solution:
    def removeDuplicates(self, nums: List[int]) -> int:

        #array is sorted so pointers can be used directly
        #i did not see returning the number of unique elements
        i=0
        if not nums:
            return 0
        for j in range(1, len(nums)):
            if nums[i]!=nums[j]:
                i=i+1
                nums[i]=nums[j]
        return i+1
```
