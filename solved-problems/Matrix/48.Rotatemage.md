## 4) Final approach (in plain English)

- transpose the matrix with nested for loops
- reverse the rows using left and right pointers and looping over the rows in the matrix

## 5) Code (final)

```python
class Solution:
    def rotate(self, matrix: List[List[int]]) -> None:
        """
        Do not return anything, modify matrix in-place instead.
        """

        n=len(matrix)
        for i in range(n):
            for j in range(i+1,n):
                matrix[i][j], matrix[j][i]=matrix[j][i], matrix[i][j]

        for row in matrix:
            left=0
            right=n-1
            while left<right:
                row[left], row[right]=row[right], row[left]
                left+=1
                right-=1
        return matrix
```
