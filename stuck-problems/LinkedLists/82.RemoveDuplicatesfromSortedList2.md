## 4) Final approach (in plain English)

1. First, I traverse the linked list and use a dictionary to count how many times each value appears.
2. I create a dummy node before the head and use `prev` and `node` pointers to traverse the list.
3. If a value appears more than once, I skip that node using `prev.next = node.next`; otherwise, I move `prev` forward.
4. Finally, I return `dummy.next`, which points to the updated linked list without any duplicated values.
   Steps of the solution like you’d explain to a friend.

## 5) Code (final)

```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
class Solution:
    def deleteDuplicates(self, head: ListNode | None) -> ListNode | None:
        nums_map={}
        node=head

        while node:
            nums_map[node.val]=nums_map.get(node.val,0)+1
            node=node.next

        dummy=ListNode(0)
        prev=dummy
        dummy.next=head
        node=head

        while node:
            if nums_map[node.val]>1:
                prev.next=node.next
            else:
                prev=node
            node=node.next
        return dummy.next
```
