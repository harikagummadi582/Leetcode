## 4) Final approach (in plain English)

- Start at the root with the given target sum.
- At each node, subtract its value from the remaining sum.
- If you reach a leaf node, check whether the remaining sum is zero.
- Otherwise, recursively check the left and right subtrees.
- Return True if either subtree has a valid path; otherwise, return False.
  Steps of the solution like you’d explain to a friend.

## 5) Code (final)

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def hasPathSum(self, root: TreeNode | None, targetSum: int) -> bool:

        def search(node, currsum):
            if not node:
                return False

            currsum-=node.val
            if not node.left and not node.right:
                return currsum==0
            return search(node.left, currsum) or search(node.right, currsum)
        return search(root, targetSum)
```
